Privacy Policy

Last updated: April 8, 2026

Opket is a server-based shared room app for chat, voice, music, and watch sessions. Most data stays on the user's device, while shared activity is synchronized through realtime messaging infrastructure.

What We Collect

The app can process the following categories of data when you use it:

  • Messages, reactions, and shared room activity created inside the app
  • Profile names, emoji avatars, uploaded photos, sketches, shared links, and media files you choose to send
  • Local preferences such as language, notifications, and device security settings
  • Server codes and encrypted event payloads needed to keep connected members in sync
  • Temporary camera and microphone streams only when you explicitly start or join a live session

How Data Is Used

  • To synchronize chat, voice presence, music queues, and watch room state between connected members
  • To save local preferences on your own device
  • To deliver retained events safely when a member reconnects later
  • To provide optional live camera and microphone features between members already connected to the same room

Storage And Sharing

Most app data is stored locally in your browser storage on your own device. Shared content is sent through the app's realtime messaging layer so it can reach other devices connected to the same server. If server members configure the same optional shared secret, encryption key derivation is strengthened with that shared secret.

The app does not include a full account system or dedicated backend identity layer at this time.

Camera and microphone streams are used for live session delivery and are not described as a long-term archive feature inside this app wrapper.

Permissions

  • Camera permission is requested only if you choose to start a video session
  • Microphone permission is requested only if you choose to join or start a voice session

Security

  • Content is encrypted in transit inside the app's messaging flow
  • Optional shared server secret support strengthens key derivation
  • Optional device PIN lock can protect local access on the same device

No system can guarantee absolute security. Users should avoid storing highly sensitive legal, financial, medical, or government identity data in the app.

Children

This app is not designed for children.
